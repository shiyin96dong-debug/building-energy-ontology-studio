IMPLEMENTATION / REFERENCE

10-stage Pipeline

Read-only outline of the original Python / spaCy implementation. These modules run in the private local project; this web page does not execute Python or upload documents.

Verified source corpus

19 public EnergyPlus and Ladybug documentation pages, 25 curated ontology concepts, 39 page-concept relations. Full semantic parsing and general coreference resolution are not claimed.
